# Cheatsheet: semiotics-decoding shelf

Routing tables and quick rules. When unsure which model applies, start here; the steps live in patterns.md, the theory in the chapters.

## Routing: what you are looking at

| Situation | Which model applies | Check first |
|---|---|---|
| A visual artifact (ad, outfit, menu, physique post, render) | Three-message model (rhetoric-of-the-image) | Transcribe the denoted inventory in flat literal language before naming any connotation |
| A message dividing its audience | Three-position typology (encoding-decoding) | Identify the preferred reading, then test for opposition before diagnosing misunderstanding |
| A claim presenting as obvious, natural, or timeless | Myth as second-order system (mythologies) | What history was removed, and who benefits from the removal |
| A term or sign whose meaning is shifting | Value and paradigm (course-in-general-linguistics) | The neighbors: a drift in one term implies repricing across the set |
| A behavior with no stable name yet | Undercoding (theory-of-semiotics) | The competing provisional labels; the winner reveals which code won |
| Machine-replicable content, human-vs-AI dispute | Ratio facilis vs difficilis (theory-of-semiotics) | Is expression stamped from an existing type, or invented from content |
| An AI-generated image | Having-been-there void (rhetoric-of-the-image) | Where the denoted layer certifies nothing, style is smuggling in the naturalization |
| A caption, headline, or on-image text | Anchorage vs relay (rhetoric-of-the-image) | Which reading the producer is paying to enforce |
| A brand or creator prominently admitting a flaw | Inoculation (mythologies) | Whether the small confessed evil is shielding the principal one |
| A pile of posts you must turn into insight | Langue vs parole (course-in-general-linguistics) | Do not report parole; infer the shared rules that make the posts sayable |
| A segment endorsing a frame but defecting in its own case | Negotiated code (encoding-decoding) | Log it as the modal position, not an inconsistency |
| Proliferating microgenres or taxonomies | Overcoding (theory-of-semiotics) | Read for subcode boundaries; expect fragmentation along them |
| A sign pointing at something that does not exist | Cultural unit (theory-of-semiotics) | Analyze the cultural unit anyway; nonexistent referents are often the strongest signals |
| A meaning everyone in a scene treats as plain reality | Naturalized code (encoding-decoding) | Who encoded it and what infrastructure keeps it in place |
| You need to counter a frame, not describe it | Counter-myth (mythologies) | Do not fact-check the first order; surface the second |

## Routing: instruments

| Instrument | What this shelf supplies | Check first |
|---|---|---|
| Daily trend read | The semiotic pre-pass (decode the sign, name the code, state the promise-delivery gap); the three-message pass for visuals; preferred reading plus live counter-readings on divided stories | On a divided story, state the preferred reading and the counter-readings, never one summary |
| Audience simulation (rule sets + sims) | Rule set as langue inferred from parole; code and lexicon inventories; paradigmatic choice sets; per-agent decoders with dominant/negotiated/oppositional weights | Never give all agents the same decoder; encode once, decode per agent |
| Forecast ensemble | Frame-first forecasting: re-codings not artifacts, naturalization depth as durability, connotator drift, modal position migration, community cohesion | The leading indicator is the frame moving before the messages do |

## Red flags: the figures of myth

| You observe | Figure | It signals |
|---|---|---|
| A small flaw confessed loudly | inoculation | The principal evil is being immunized |
| The object appears from nowhere | privation of history | Naturalization at work; hunt the erased making |
| "It is what it is," paraphrase refused | tautology | The frame is defending itself, not the content |
| Both poles rejected to stand above the fray | neither-norism | The question itself is being dodged |
| Effects counted, meaning skipped | quantification of quality | Ideology hiding behind metrics |
| Proverb-voiced certainty | statement of fact | Depoliticized speech; politics removed from a political claim |
| The other rendered as a version of the self, or exotic | identification | Difference being erased or quarantined |
| The beneficiary is never named | ex-nomination | Dominant interests reading as universal |

## Quick rules

1. "Natural," "obvious," and "timeless" are findings, not endpoints. Name the code, the convention, and the community holding it.
2. Denote before you connote. The literal inventory comes first, always, or you hallucinate meanings.
3. Never adjudicate the true reading of a divided message. Classify the readings and report the distribution.
4. The fight is at connotation. When a dispute presents as being about literal meaning, a naturalized code is doing the work.
5. Parole is evidence, langue is the object. A pile of posts is not insight; the inferred rule system is.
6. Read synchronically first; then hunt the history that naturalization removed. Origins do not explain current use, but their erasure is the ideological move.
7. Read choices against the paradigm. The signal is what the choice excluded, not the item itself.
8. Nonexistent referents are semiotically normal. Decode the cultural unit, not the world.
9. Facilis is commodity, difficilis is signal. Sort production by ratio before judging content.
10. Encode once, decode per agent. Simulated audiences without divergent decoders model message delivery, not reception.
11. Forecast the frame, not the artifact. Watch position migration, naturalization depth, connotator drift, and the cohesion of the convention-holding community.
12. Do not fact-check myth. It concedes the facts and keeps the frame; surface the second order instead.
