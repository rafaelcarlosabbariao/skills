# A Theory of Semiotics

## The claim

Culture is a network of codes that correlate expressions with contents, and meaning lives in those correlations, not in objects or intentions. Eco defines semiotics as the discipline studying everything which can be used in order to lie: whatever can misrepresent can also signify, so all of culture, from words to clothes to gestures, is readable as sign production. A message is not one meaning delivered; it is a form that different codes can legitimately actualize in different ways, which is why open texts sustain multiple valid readings.

## Core claims

- There is no fixed sign, only the sign-function: a transitory correlation between an expression plane and a content plane. Codes make and unmake these correlations, so meanings drift as cultures re-code.
- Meaning is a cultural unit, not a referent. Decoding means asking what the culture maps a sign to, never what the world contains. Signs work fine about nonexistent things, which is the referential fallacy's refutation.
- Semiosis is unlimited: every interpretant of a sign is another sign. Culture behaves like an encyclopedia, a network you traverse, not a dictionary of final definitions.
- Codes stratify. Overcoding builds ever more specific subcodes on established ones (genre, style, iconography, etiquette). Undercoding builds rough provisional codes where no precise code exists yet.
- Sign production divides by labor. Ratio facilis stamps tokens from an existing expression type. Ratio difficilis invents expression directly from content when no type exists. Iconism is not natural resemblance; it is convention layered on convention.
- Sender and receiver rarely hold identical codes, so divergent decoding is structural, not error.

## Frameworks and models

**Theory of codes.** An s-code is a system of internal differences (a repertoire); a code proper is the rule correlating one system to another (expression to content). Denotative codes ground first-order meanings; connotative subcodes ride on top of them. The operative structure is the two-plane correlation plus the stack of subcodes above it.

**The encyclopedia (Model Q).** Borrowed from Quillian's semantic memory model: a sememe is a node in an n-dimensional network of interpretants, each defined by other nodes without a final term. Practical consequence: compile meanings as networks with paths, not as glossary entries.

**Overcoding, undercoding, extra-coding.** Overcoding: applying further rules to already coded material, generating subcodes (microgenres, aesthetic taxonomies, house styles). Undercoding: assigning rough global meaning to imprecisely understood material, the normal state when reading a new scene. Most real interpretation is extra-coding, a mix of both running simultaneously.

**Typology of sign production.** Four modes: recognition (imprints, symptoms, clues), ostension (showing a sample as its class), replica (tokens from a type, ratio facilis), invention (mapping content to new expression, ratio difficilis). A production continuum replaces the naive icon versus symbol split.

**Semiotic thresholds.** Lower threshold: physical stimuli and signal passage below culture (information theory territory). Upper threshold: the whole of culture treated as communication. Semiotics operates between them.

## Decision rules

- If a sign's meaning feels obvious, name the code that makes it obvious. The obviousness is the finding, not the endpoint.
- If audiences split on a message, do not adjudicate the true reading. Map which subcode each cluster is running; the split is data about code distribution.
- If a behavior has no stable name yet, treat it as undercoding in progress. Track the competing provisional labels; the winning label reveals which code won.
- If content is machine-replicable at scale, sort by ratio: facilis tokens are commodity, difficilis inventions carry the cultural signal.
- If a sign points at something that does not exist (an aesthetic, a nostalgia, a lifestyle), analyze the cultural unit anyway. Nonexistent referents are semiotically normal and often the strongest signals.
- If a field is overcoding fast (proliferating microgenres or taxonomies), expect audience fragmentation and read for the subcode boundaries.

## Key terms

- sign-function: a transitory correlation of an expression with a content, made by a code.
- code: the rule correlating elements of one system with elements of another.
- cultural unit: the meaning a culture assigns, independent of any real referent.
- interpretant: another sign that translates a sign; the engine of unlimited semiosis.
- encyclopedia: meaning as a traversable network of interpretants, against the dictionary model.
- overcoding: building more specific subcodes on top of existing codes.
- undercoding: rough provisional coding of not-yet-understood material.
- ratio facilis / ratio difficilis: production from an existing type versus invention of a new one.
- semiotic threshold: the lower and upper bounds between signals, semiosis, and culture at large.
