# Cheatsheet

Situation to model to first check. Rows route to a chapter (`chapters/<slug>.md`) or a pattern (patterns.md).

## Reading a surge (daily trend read)

| Situation | Model | Check first |
|---|---|---|
| Evidence is mostly popularity metrics ("everyone is doing X") | Social proof (influence-cialdini) | Is the proof real behavior or manufactured engagement; uncertainty and similarity amplifiers present? |
| Drops, waitlists, countdowns driving demand | Staged scarcity (influence-cialdini) | Supply-driven or staged? If staged, expect spike then reversal; not a taste shift |
| Trend feels huge because examples come easily | Availability (thinking-fast-and-slow) | Mention volume vs base rates and sibling systems, same run |
| Daily metric hits an extreme | Regression to the mean (thinking-fast-and-slow) | Second independent reading before narrating a turn |
| Content winning on liking with heavy repetition | Fluency / mere exposure (thinking-fast-and-slow, brain-on-music) | Exposure position on the inverted-U; does liking survive an exposure drop? |
| Content restricted or banned, then surging | Reactance (influence-cialdini) | Censorship reads as amplification; separate reactance value from underlying demand |
| New track or sound spreading | Timbre first (brain-on-music) | New timbre = scene forming; old timbre, new lyrics = format repeat |
| Flood of schema-perfect content | Surprisal test (brain-on-music, pattern 4) | Prediction error present or absent per item; absent = slop-adjacent |
| Revival or nostalgia wave | Cohort clock (brain-on-music, pattern 11) | Charting year + 14 to 22 = driving age band; math fails = tastemaker push |

## Reading a fight

| Situation | Model | Check first |
|---|---|---|
| Fact fight, neither side updates | Values conflict (righteous-mind) | Code both sides by foundation; file as values conflict, debunking will not move it |
| Verdict survives refutation of every stated reason | Taboo / moral dumbfounding (righteous-mind) | Forecast persistence; do not argue it |
| Purity words out (clean, raw, natural, toxic, slop) | Sanctity active (righteous-mind) | Expect disgust-driven virality and hard in/out boundaries |
| Feud will not die | Echo effect (evolution-of-cooperation) | Two provocable unforgiving strategies? Fix is a forgiveness mechanic, not a values appeal |
| Minimal cues (emoji, slang, badge) sorting people | Minimal groups (power-of-us) | Expect full favoritism dynamics quickly; do not wait for substantive disagreement |
| New "we" label plus a named enemy | Identity entrepreneurship (power-of-us, pattern 6) | Track the entrepreneur and the prototype they perform, not just the content |
| Two groups escalating | Conflict triage (pattern 8) | In-group love vs out-group hate first; favoritism responds to superordinate framing, hate does not |
| Committed insiders publicly criticizing their own group | Normative dissent (power-of-us) | Read norm shift, not collapse; leading indicator |
| Synchronized ritual (chants, meme lockstep) | Hive switch (righteous-mind) | Expect spiking loyalty, suppressed dissent, short half-life unless institutionalized |

## Reading an audience (audience simulation)

| Situation | Model | Check first |
|---|---|---|
| Audience made public identity commitments | Commitment/consistency (influence-cialdini) | Reframe the commitment, never attack it; consistency beats counterevidence |
| Stated beliefs look extreme or absurd | Expressive responding (power-of-us, pattern 7) | Identity salience at statement time; add stakes to recover real belief |
| Choosing which framing to test | Foundation profile (righteous-mind) + framing (thinking-fast-and-slow) | Six-weight vector per segment; loss frames vs the segment's reference point |
| Encoding agents for simulation | Agent parameterization (pattern 13) | Pick agent type per question: payoff, bias, or identity; do not blend into one blob |
| Advising a creator's audience strategy | Four properties (evolution-of-cooperation) | Nice, provocable once, forgiving, clear; never defect first on your audience |
| Dating an audience's core canon | Crystallization window (brain-on-music) | Median age minus 14 dates the canon; prediction-error appetite sets novelty dose |
| Lonely-skewing audience | Liking + reciprocity at scale (influence-cialdini); low-w society (evolution-of-cooperation) | Parasocial cue susceptibility runs higher; bonding function unmet in adjacent domains |

## Forecasting (forecast ensemble)

| Situation | Model | Check first |
|---|---|---|
| Any high-conviction narrative forecast | WYSIATI + outside view (thinking-fast-and-slow, pattern 14) | Reference-class base rate first; premortem before shipping |
| Cascade or adoption forecast | Social proof feedback (influence-cialdini) | Social proof is the positive-feedback term; is the seed proof real? |
| Exploitative strategy currently winning | Ecological replay (evolution-of-cooperation) | It consumes its own prey; forecast collapse when naive cooperators exit |
| Cooperative norm appearing in a hostile scene | Cluster invasion (evolution-of-cooperation, pattern 10) | Find the dense cluster; established nice norms ratchet one way, forecast lock-in |
| Identity mobilization detected | Moral contagion (power-of-us) | Add a mobilization branch; weight containment by network boundedness |
| Backlash forecast for a trigger | Foundation loading (righteous-mind) | Which foundation loads? Sanctity spreads on disgust and persists longest |
| Track or format trajectory | Inverted-U (brain-on-music) | Saturation-then-decay shape; exposure position sets where on the curve |

## Standing cautions

- Analyst intuition is not audience intuition. The audience's System 1 is the data; yours is the hazard. Culture reading lacks the regular structure and fast feedback that make intuition trustworthy, so defer to the instrument (thinking-fast-and-slow).
- Behavioral priming replicated poorly; keep the fluency and heuristics core, hold priming claims loosely (thinking-fast-and-slow).
- Foundation profiles come from WEIRD-skewed samples; use the slopes across ideology, not absolute scores (righteous-mind).
- Do not over-ascribe values: Axelrod gets cooperation from self-interested agents with no goodwill. Read w and payoffs before reading character (evolution-of-cooperation).
- Confidence tracks story coherence, not evidence quality. The more satisfying the cultural explanation, the bigger the discount (thinking-fast-and-slow).
