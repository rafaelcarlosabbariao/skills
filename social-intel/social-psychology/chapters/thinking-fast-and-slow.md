# Thinking, Fast and Slow

## The claim

Human judgment runs on two systems: System 1, fast, automatic, associative, and effortless; System 2, slow, deliberate, and lazy. Because System 2 mostly endorses whatever System 1 hands it, judgment is systematically biased in predictable directions, and those biases, not rational preference, drive most everyday choice. For this practice the point sharpens to: most cultural choice runs on System 1 heuristics, which is why trends bypass deliberation.

## Core claims

- System 1 generates impressions continuously and cannot be switched off; System 2 rations attention and usually rubber-stamps System 1's output.
- Hard questions get silently swapped for easy ones (substitution): "is this true" becomes "does this feel familiar," "is this good" becomes "do I like how it feels."
- WYSIATI: the mind builds the most coherent story from available evidence and does not register what is missing. Confidence tracks story coherence, not evidence quality.
- Cognitive ease is mistaken for truth and quality: repetition raises fluency, and fluency raises belief and liking (mere exposure).
- People are loss averse and reference-dependent: outcomes are coded as gains or losses from a reference point, and losses weigh roughly twice as much as gains.
- Intuitive prediction ignores base rates and regression to the mean; extreme observations are followed by less extreme ones for statistical reasons, then narrated as causal stories.
- Expert intuition is trustworthy only in high-validity environments with regular structure, prolonged practice, and fast feedback. Culture reading is not such an environment by default.

## Frameworks and models

**Dual-process model (System 1 / System 2).** System 1: parallel, associative, emotional, no sense of voluntary control. System 2: serial, effortful, capable of rule-following and statistical thinking, but depletable and reluctant. Design implication: any message, product, or trend that only needs System 1 spreads faster than one that requires System 2.

**Heuristics.** Availability (frequency judged by ease of recall; feeds availability cascades, where coverage inflates recall, which inflates perceived importance, which drives more coverage). Representativeness (probability judged by similarity to a stereotype; produces base-rate neglect and the conjunction fallacy, the Linda problem). Anchoring (estimates drag toward any prior number; anchoring index around 55% in the classic experiments). Affect (risk and benefit judged by feeling).

**Prospect theory (with Tversky, 1979).** Value is defined over changes, not states: v(x) = x^a for gains, v(x) = -l(-x)^a for losses, with a about 0.88 and loss aversion l about 2.25 (1992 cumulative version estimates). Probability weighting overweights rare events and underweights near-certain ones (weighting parameter about 0.61 for gains), producing the fourfold pattern: risk-seeking for long-shot gains and probable losses, risk-averse for probable gains and long-shot losses. Framing the same fact as loss versus gain flips choices.

**Inside view vs outside view.** The inside view forecasts from the specifics of the case and produces the planning fallacy. The outside view starts from the base rate of a reference class, then adjusts. Reference-class forecasting is the corrective.

**Two selves.** The experiencing self lives moments; the remembering self scores them by peak and end (peak-end rule) and ignores duration (duration neglect). Choices serve the remembering self.

**Caveat.** The social-priming chapters (Florida effect and kin) have replicated poorly since 2011. Keep the fluency and heuristics core; hold behavioral priming loosely.

## Decision rules

- If a trend feels large because examples come easily to mind, treat it as an availability reading, not a behavior reading: check mention volume against base rates and sibling systems before calling a shift.
- If a daily metric hits an extreme, expect regression to the mean; require a second independent reading before narrating a turn.
- If content is winning, ask whether fluency explains it before crediting quality: repetition alone manufactures liking.
- If a cultural explanation feels satisfyingly coherent, discount confidence in proportion to that coherence (WYSIATI).
- When forecasting, start from a reference class base rate, then adjust with case specifics, never the reverse.
- When modeling audience response, weight losses about 2x gains and code reactions against the audience's reference point, not the absolute stimulus.
- Trust an intuitive read only where the environment gives regular structure and fast feedback; otherwise defer to the instrument.

## Key terms

- **System 1:** fast, automatic, associative cognition; the default driver of judgment.
- **System 2:** slow, effortful, deliberate cognition; lazy and depletable.
- **WYSIATI:** what you see is all there is; coherence from available evidence, blindness to missing evidence.
- **Substitution:** answering an easier question in place of the hard one asked.
- **Availability cascade:** self-reinforcing loop where coverage inflates recall, which inflates perceived importance.
- **Loss aversion:** losses weigh roughly 2.25x equivalent gains.
- **Anchoring:** estimates drag toward a prior number, moving about 55% of the way in classic tests.
- **Base-rate neglect:** ignoring background frequencies in favor of case-specific stories.
- **Peak-end rule:** remembered experience scored by its peak moment and its ending, not its duration.
- **Outside view:** forecasting from a reference class base rate before adjusting for the case.
