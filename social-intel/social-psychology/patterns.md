# Patterns

Reusable recipes that emerge across the shelf. Each names its source works; open the chapter files for the underlying evidence.

## 1. Lever attribution scan

**When to use:** a trend, product, or creator is surging and the daily read needs to say why before crediting culture.

**Steps:**
1. Tag which of the six levers is carrying the surge: reciprocity, commitment/consistency, social proof, authority, liking, scarcity.
2. Check the amplifier conditions for that lever: social proof needs uncertainty plus similarity; scarcity needs recency plus visible rivalry; commitment needs active, public, effortful, uncoerced acts.
3. Check provenance: is the proof real behavior or manufactured engagement; are the authority cues substance or aesthetics; is the scarcity supply-driven or staged.
4. Write the dial read as "lever X carrying it" before any cultural story.

**Source works:** influence-cialdini.

## 2. Availability audit

**When to use:** a trend feels large, a metric hits an extreme, or coverage is snowballing.

**Steps:**
1. Ask whether the size impression comes from ease of recall (coverage, feed density) rather than measured behavior.
2. Check mention volume against base rates and sibling systems in the same run before calling a shift (system-specific is a finding, corpus-wide is plumbing).
3. On an extreme daily reading, expect regression to the mean; require a second independent reading before narrating a turn.
4. If coverage and recall are feeding each other, log an availability cascade and forecast its decay separately from the behavior underneath.

**Source works:** thinking-fast-and-slow.

## 3. Fluency versus taste test

**When to use:** content is "winning" on liking metrics and the question is whether taste actually moved.

**Steps:**
1. Estimate exposure position: how many times has this audience already met this content or format.
2. Early curve with heavy repetition: read the liking spike as a fluency artifact (mere exposure), not a taste shift.
3. Locate the object on the inverted-U: unfamiliar, loved, or exhausted. Recommendation feeds optimize for schema fit, the boring end of the curve.
4. Forecast: fluency-driven liking saturates then decays as exposure keeps climbing; genuine taste movement survives a drop in exposure.

**Source works:** thinking-fast-and-slow, brain-on-music.

## 4. Surprisal test for slop

**When to use:** deciding whether a content wave is human work or generated slop before crediting it to taste.

**Steps:**
1. Per item, tag prediction error present or absent: does the piece set up an expectation and then bend or withhold the payoff, or does it fit its genre schema perfectly.
2. Schema-perfect output with no deliberate violation is slop-adjacent regardless of production quality; regression to the schema mean is the machine signature.
3. Cross-check the trust cues: is engagement forged (social proof), are credentials aesthetic (authority), is the whole package optimized to pass System 1 with zero System 2 engagement.
4. Expect slop to win on reach while losing on remembered value (peak-end); track the two separately.

**Source works:** brain-on-music, thinking-fast-and-slow, influence-cialdini.

## 5. Foundation coding pass

**When to use:** scoring the values or gender pressure systems, or any fight where neither side updates on facts.

**Steps:**
1. Code each side's language by the six foundations: Care, Fairness (as proportionality), Loyalty, Authority, Sanctity, Liberty.
2. Build each side's six-weight profile; the profile predicts which framings land and which register as noise.
3. Flag purity and contamination vocabulary (clean, raw, natural, toxic, slop) as active Sanctity even in secular scenes; expect disgust-driven virality and hard boundaries.
4. If a verdict survives refutation of all its stated reasons, file it as a taboo and forecast persistence.
5. Report the fight as a values conflict, not an information gap; debunking will not move it.

**Source works:** righteous-mind.

## 6. Identity entrepreneurship watch

**When to use:** a new "we" label, badge, emoji, or slang term starts sorting people.

**Steps:**
1. Log the entrepreneur: who is defining the category, performing its prototype, setting its norms, and naming its rival. Track the person, not just the content.
2. Treat minimal cues as sufficient: do not wait for substantive disagreement before expecting full in-group favoritism dynamics.
3. Count moral-emotional word density in the label's discourse (diffusion multiplier roughly 1.2x per moral-emotional word).
4. Map the network boundary: moral contagion is in-network bounded, so forecast containment where the identity network ends.
5. In the trend read, treat new we/they labels in the language domain as leading indicators for spikes in other domains.

**Source works:** power-of-us.

## 7. Expressive-belief discount

**When to use:** stated beliefs, poll answers, or comment-section positions need to be read as data.

**Steps:**
1. Check identity salience at the moment of statement; under high salience, stated belief is expressive by default.
2. Apply the "Can I believe it?" discount when engagement runs high on a claim the community wants true.
3. To recover actual belief, add cost or accuracy stakes (small accuracy incentives shrink partisan factual gaps by roughly half).
4. If a claim spreads fast but stays inside one identity network, read loyalty signaling, not information transfer.

**Source works:** power-of-us, righteous-mind.

## 8. Conflict triage

**When to use:** any escalating fight, before prescribing anything.

**Steps:**
1. Test for a values conflict (Haidt): do the sides' foundation profiles diverge, and do verdicts survive refutation? If yes, the fix is reframing into the other matrix, elephant first.
2. Test for identity favoritism (Van Bavel and Packer): did minimal cues sort the camps, and is the energy in-group love rather than out-group hate? If yes, superordinate framing can work; hate-driven conflict does not respond to it.
3. Test for a payoff echo (Axelrod): are two provocable, unforgiving strategies locked in alternating retaliation traceable to an old defection? If yes, the fix is a forgiveness mechanic, not a values appeal.
4. Only after triage, prescribe. The three fixes are not interchangeable, and prescribing across diagnoses fails.

**Source works:** righteous-mind, power-of-us, evolution-of-cooperation.

## 9. Shadow-of-the-future read

**When to use:** diagnosing trust, civility, or defection levels in a scene, platform, or domain.

**Steps:**
1. Estimate w: churn, anonymity, and algorithmic strangers push interactions toward one-shot; durable membership and repeat matching raise w.
2. If interactions are effectively one-shot, predict defection behaviors (scams, slop, ghosting, dunking, extraction) and read structure before reading character.
3. Check recognition: can actors identify past partners and recall past actions? Reputation only binds where recognition works.
4. To forecast or advise repair, use the levers: enlarge the shadow of the future, change payoffs, teach reciprocity, improve recognition.
5. Carry the threshold: reciprocal cooperation is stable when w clears roughly 2/3 under standard payoffs; a scene sliding below its threshold flips fast.

**Source works:** evolution-of-cooperation.

## 10. Cluster scan

**When to use:** a cooperative norm (civility pact, human-made pledge, moderation ethic) is appearing inside a hostile scene.

**Steps:**
1. Find the cluster: the small dense group interacting mostly with each other that carries the norm. Individuals cannot seed norms in hostile populations; clusters can.
2. Check the ratchet: cooperator clusters can invade defector populations, defector clusters cannot invade nice ones, so an established cooperative norm forecasts as durable.
3. If an exploitative strategy is winning instead, forecast collapse: exploiters consume their own environment and starve when naive cooperators exit.

**Source works:** evolution-of-cooperation.

## 11. Cohort clock

**When to use:** a revival, reissue, or nostalgia wave is trending and the question is who is driving it.

**Steps:**
1. Take the charting year of the original material.
2. Add 14 to 22 years (taste crystallizes roughly ages 12 to 22, pivot 14) to get the age band that should be driving a genuine revival.
3. Check the actual audience against the band. If the math works, it is cohort nostalgia riding multiple-trace memory; forecast strength inside that cohort.
4. If the math fails, it is a tastemaker push, not nostalgia; forecast it with lever attribution (pattern 1) instead.

**Source works:** brain-on-music.

## 12. Elephant-first message plan

**When to use:** advising a creator or brand on how to move an audience, or predicting which framing lands.

**Steps:**
1. Choose an identity-congruent messenger; influence flows from being seen as one of us, not from position or credentials.
2. Lead with intuition: affect and identity first, reasons second. Arguments work on intuitions, not logic.
3. Match the framing to the audience's foundation profile; messaging that loads only Care and Fairness underperforms with conservative-leaning and non-WEIRD segments, so widen the mix to widen reach.
4. Frame against the audience's reference point and prefer loss frames where honest; losses weigh about 2.25x gains.
5. If the audience has made public commitments, reframe the commitment rather than attack it; consistency pressure beats counterevidence.

**Source works:** righteous-mind, power-of-us, thinking-fast-and-slow, influence-cialdini.

## 13. Audience agent parameterization

**When to use:** encoding a creator's audience into rule sets for agent-based simulation.

**Steps:**
1. Pick the agent type for the question: payoff agents (Axelrod) for strategy and structure tests, bias agents (Kahneman) for framing and dose tests, identity agents (Van Bavel, Haidt) for mobilization and containment tests. Do not blend all three into one blob.
2. Compliance layer: give each segment a sensitivity profile across the six levers, per-lever compliance probabilities and doses.
3. Judgment layer: write rules as System 1 heuristics (substitution, affect, anchoring); carry loss aversion around 2.25 and reference dependence, not rational preference.
4. Identity layer: encode identity stacks with salience triggers, belonging goals that can override accuracy goals, and dissent thresholds among high-identifiers.
5. Moral layer: give each segment a six-weight foundation vector; test framings against it.
6. Strategy layer: encode the four properties (nice, provocable, forgiving, clear) plus w; test creator strategies tournament-style with ecological replay.
7. Content layer: give each segment a prediction-error appetite and a crystallization anchor (median age minus 14 dates the core canon).

**Source works:** evolution-of-cooperation, thinking-fast-and-slow, power-of-us, righteous-mind, influence-cialdini, brain-on-music.

## 14. Outside-view forecast setup

**When to use:** any forecast ensemble or high-conviction call before it ships.

**Steps:**
1. Start from a reference class base rate, then adjust with case specifics, never the reverse.
2. Treat confident single-narrative forecasts as WYSIATI; discount confidence in proportion to how satisfying the story is, and run a premortem on any high-conviction call.
3. Add mechanism-shaped trajectories from the shelf: staged scarcity gives spike-then-reversal; the inverted-U gives saturation-then-decay; exploiter booms self-terminate; cooperative norms enter via clusters then lock in.
4. Add an identity-mobilization branch whenever an entrepreneur plus enemy-naming is detected, weighting containment by network boundedness.
5. Trust an intuitive override only where the environment has regular structure and fast feedback; culture reading is not that environment by default, so defer to the instrument.

**Source works:** thinking-fast-and-slow, influence-cialdini, brain-on-music, evolution-of-cooperation, power-of-us.
